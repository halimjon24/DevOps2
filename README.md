# Задание 2.1 — Анализ логов Nginx и отправка сообщения в Telegram

## Описание

Цель программы — проанализировать файл лога веб-сервера Nginx, найти IP-адреса, с которых было выполнено большое количество запросов с ошибкой `404`, и отправить предупреждение в Telegram.

В программе используется порог **5 ошибок 404**. Это сделано для того, чтобы работу программы было удобно проверить на небольшом тестовом файле.

---

## 1. Какие библиотеки используются в скрипте?

В программе используются три библиотеки и модуля Python:

### `re`

`re` — стандартный модуль Python для работы с регулярными выражениями.

В программе используется функция:

```python
re.findall(...)
```

Она позволяет найти в тексте все совпадения с заданным шаблоном.

В данном случае регулярное выражение используется для поиска IP-адресов, запросы которых завершились HTTP-кодом `404`.

### `collections.Counter`

`Counter` — класс из стандартного модуля `collections`.

Он используется для подсчёта количества повторений элементов.

В программе:

```python
counts = Counter(ips)
```

создаётся счётчик IP-адресов. Благодаря этому можно определить, сколько ошибок `404` получил каждый IP-адрес.

Например, если IP встретился 6 раз, программа определит:

```text
192.168.1.10 -> 6
```

### `requests`

`requests` — сторонняя библиотека Python для выполнения HTTP-запросов.

В этой программе она используется для отправки POST-запроса к Telegram Bot API:

```python
requests.post(...)
```

С помощью этого запроса программа отправляет пользователю сообщение с результатом анализа.

Установка библиотеки:

```bash
pip install requests
```

---

## 2. Какое окружение нужно обеспечить?

Для запуска программы необходимо:

1. Установить Python 3.
2. Установить библиотеку `requests`:

```bash
pip install requests
```

3. Создать файл `access.log` с логами веб-сервера.
4. Положить `access.log` в ту же папку, что и программу, либо указать путь к нему в переменной `LOG_FILE`.
5. Создать Telegram-бота.
6. Получить токен Telegram-бота.
7. Получить `CHAT_ID` пользователя или чата, которому необходимо отправлять сообщение.
8. Компьютер должен иметь доступ к Интернету.

### Важное замечание о безопасности

Токен Telegram-бота является секретным ключом. Его нельзя публиковать в открытом GitHub-репозитории.

Поэтому в опубликованном коде используются:

```python
TELEGRAM_TOKEN = "YOUR_BOT_TOKEN"
CHAT_ID = "YOUR_CHAT_ID"
```

Перед запуском необходимо заменить их на свои значения.

Если настоящий токен уже был опубликован, его следует перевыпустить через `@BotFather`.

## Как работает программа

Работа программы состоит из нескольких этапов:

```text
access.log
    ↓
Чтение файла
    ↓
Поиск запросов с кодом 404
    ↓
Определение IP-адресов
    ↓
Подсчёт количества ошибок для каждого IP
    ↓
Проверка порога THRESHOLD
    ↓
Формирование сообщения
    ↓
Отправка сообщения в Telegram
```

---

## Запуск программы

Сначала необходимо установить `requests`:

```bash
pip install requests
```

После этого нужно указать свой токен и `CHAT_ID` в `analyze_log.py`.

Затем выполнить:

```bash
python analyze_log.py
```

Если обнаружен IP с большим количеством ошибок, программа отправит сообщение:

```text
Обнаружена подозрительная активность!

IP 192.168.1.10 получил 6 ошибок 404
```

Если таких IP нет:

```text
Подозрительной активности не обнаружено.
```

---

## Результат работы

Таким образом, программа выполняет часть функционала исходного задания:

- читает файл лога;
- ищет ошибки `404`;
- определяет IP-адреса;
- подсчитывает количество ошибок;
- определяет подозрительную активность;
- отправляет результат пользователю в Telegram.

# Задание 2.2 — Проверка доступности сайтов

## Описание

Программа читает из файла `link.txt` адреса сайтов, проверяет их доступность и записывает результат в файл `report.txt`.

Формат результата:

```text
адрес -> Ok
```

или:

```text
адрес -> Error
```

## Используемая библиотека

Для проверки сайтов используется библиотека `requests`.

Установка:

```bash
pip install requests
```

## Как работает программа

1. Открывает файл `link.txt`.
2. Читает адреса сайтов.
3. Для каждого адреса выполняет HTTP-запрос.
4. Если запрос выполнен успешно, записывает `Ok`.
5. Если произошла ошибка или сайт вернул неуспешный HTTP-статус, записывает `Error`.
6. Сохраняет результаты в `report.txt`.

## Запуск

```bash
python check_sites.py
```

После запуска создаётся файл:

```text
report.txt
```

Например:

```text
https://google.com -> Ok
https://github.com -> Ok
https://example.com -> Ok
```

## Вывод

В задании 2.1 реализован анализ лога Nginx с поиском большого количества ошибок `404` и отправкой уведомления в Telegram.

В задании 2.2 реализована автоматическая проверка списка сайтов и сохранение результатов в отдельный файл.
