## Задание 2.3 — Парсинг курса валют

### Цель

Написать Python-скрипт, который получает страницу сайта с курсами валют, анализирует HTML-код страницы и выводит курсы покупки и продажи валют.

### Используемый сайт

Для парсинга используется страница:

`https://ru.myfin.by/currency/barnaul`

Скрипт отправляет HTTP-запрос с помощью библиотеки `requests`, получает HTML-код страницы и передаёт его в `BeautifulSoup`.

### Как работает программа

1. С помощью `requests.get()` отправляется запрос на страницу.
2. `raise_for_status()` проверяет, успешно ли выполнен запрос.
3. `BeautifulSoup` разбирает HTML-код.
4. Программа находит таблицу с классом `table-best`.
5. Из строк таблицы извлекаются ячейки `<td>`.
6. Из ячеек берутся:
   - название валюты;
   - курс покупки;
   - курс продажи.
7. Полученные данные выводятся в консоль отдельно для покупки и продажи.

### Код

```python
import requests
from bs4 import BeautifulSoup

url = "https://ru.myfin.by/currency/barnaul"

response = requests.get(url, timeout=10)
response.raise_for_status()

soup = BeautifulSoup(response.text, "html.parser")

buys = []
sells = []

table = soup.find("table", class_="table-best")

if table:
    rows = table.find_all("tr")

    for row in rows:
        cols = row.find_all("td")

        if len(cols) >= 3:
            currency = cols[0].get_text(strip=True)
            buy = cols[1].get_text(strip=True)
            sell = cols[2].get_text(strip=True)

            buys.append({"currency": currency, "buy": buy})
            sells.append({"currency": currency, "sell": sell})

print("Курсы покупки:")

for item in buys:
    print(f"{item['currency']}: {item['buy']}")

print()

print("Курсы продажи:")

for item in sells:
    print(f"{item['currency']}: {item['sell']}")
```

> Обрати внимание: в исходном варианте была проверка `len(cols) >= 2`, но затем использовался `cols[2]`. Поэтому безопаснее проверять `len(cols) >= 3`.

## Задание 2.4 — Проверка изменения web-страниц

### Цель

Написать программу, которая:

- считывает список адресов из файла `link.txt`;
- посещает каждую страницу;
- определяет, изменился ли её содержимое с прошлого запуска;
- сохраняет информацию о предыдущем состоянии;
- записывает результат проверки в `report.txt`.

### Принцип работы

Для определения изменений используется хеширование.

После загрузки страницы программа получает её содержимое в виде байтов и вычисляет SHA-256:

```python
current_hash = hashlib.sha256(content).hexdigest()
```

При первом запуске для страницы ещё нет сохранённого хеша, поэтому она получает статус:

```text
[NEW]
```

При следующем запуске текущий хеш сравнивается с предыдущим:

- хеши совпадают — страница не изменилась (`[OK]`);
- хеши отличаются — содержимое изменилось (`[CHANGED]`);
- если страницу не удалось загрузить — ошибка (`[ERROR]`).

Предыдущие хеши сохраняются в файле `hashes.json`.

### Файл `link.txt`

В проекте используются следующие адреса:

```text
https://youtube.com
https://google.com
https://python.org
```

Каждый URL должен находиться на отдельной строке.

Также программа позволяет использовать комментарии. Строки, начинающиеся с `#`, игнорируются.

### Основные файлы

| Файл | Назначение |
|---|---|
| `link.txt` | список web-страниц для проверки |
| `hashes.json` | сохранённые хеши страниц с предыдущего запуска |
| `report.txt` | отчёт о результатах текущего обхода |
| Python-файл | основная программа |

```text

```

При повторном запуске, если содержимое страниц не изменилось:

```text
[OK] https://youtube.com — без изменений
[OK] https://google.com — без изменений
[OK] https://python.org — без изменений
```

Если содержимое страницы изменилось:

```text
[CHANGED] https://example.com — контент изменился
```

Если страницу не удалось загрузить:

```text
[ERROR] https://example.com — ...
```
